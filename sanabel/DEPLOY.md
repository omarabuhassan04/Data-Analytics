# النشر

التطبيق منشور على Vercel. يبقى أن تُوصَل قاعدة بيانات PostgreSQL وتُضبط
متغيّرات البيئة — وهي خطوات تحتاج حسابك أنت، ولا يمكن لأحد تنفيذها نيابةً عنك.

---

## ١) قاعدة بيانات PostgreSQL

أي مزوّد يعطي سلسلة اتصال يكفي. المخطّط قياسي بلا امتدادات خاصة:

- **Neon** — <https://neon.tech> (خطة مجانية دائمة)
- **Supabase** — <https://supabase.com>
- **Vercel Postgres** — من تبويب Storage في مشروعك مباشرة

> اشترط أن يكون ترميز القاعدة **UTF8** (وهو الافتراضي لدى كل المزوّدين
> المدارين). الواجهة والبيانات عربية بالكامل، وقاعدة بترميز WIN1252 سترفض
> تخزين النصوص العربية.

انسخ سلسلة الاتصال؛ صيغتها:

```
postgresql://USER:PASSWORD@HOST/DBNAME?sslmode=require
```

---

## ٢) متغيّرات البيئة على Vercel

من لوحة المشروع: **Settings ← Environment Variables**، وأضف الثلاثة للبيئات
Production وPreview وDevelopment:

| المتغيّر          | القيمة                                                        |
| ----------------- | ------------------------------------------------------------- |
| `DATABASE_URL`    | سلسلة اتصال PostgreSQL من الخطوة ١                            |
| `AUTH_SECRET`     | قيمة عشوائية طويلة (٣٢ محرفاً فأكثر) — **لا تستخدم قيمة التطوير** |
| `SEED_PASSWORD`   | كلمة المرور الأولية للحسابات السبعة                            |

لتوليد `AUTH_SECRET`:

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
```

> `AUTH_SECRET` هو مفتاح توقيع الجلسات. من يعرفه يستطيع تزوير جلسة أي مستخدم،
> ولهذا يرفض التطبيق الإقلاع بمفتاح أقصر من ٣٢ محرفاً.

ثم أعد النشر (**Deployments ← ⋯ ← Redeploy**) حتى تُلتقط المتغيّرات.

## ٣) تجهيز الجداول والبيانات الأولية

مرّة واحدة فقط، من جهازك، مع توجيه `DATABASE_URL` إلى قاعدة الإنتاج:

```bash
DATABASE_URL="<سلسلة اتصال الإنتاج>" npx prisma db push
```

```bash
DATABASE_URL="<سلسلة اتصال الإنتاج>" SEED_PASSWORD="<كلمة مرور قوية>" npx prisma db seed
```

على ويندوز (PowerShell):

```bash
$env:DATABASE_URL="<سلسلة اتصال الإنتاج>"; $env:SEED_PASSWORD="<كلمة مرور قوية>"; npx prisma db seed
```

> **البذور تمسح الجداول وتعيد بناءها.** لذلك هي خارج سلسلة البناء عمداً: لو
> كانت ضمنها لمُحي المخزون الحقيقي مع كل نشر. شغّلها مرّة واحدة على قاعدة
> فارغة، ولا تعِدها بعد أن يبدأ الاستخدام الفعلي.

## ٤) بعد أول دخول

1. ادخل بحساب `abuhassan` وكلمة `SEED_PASSWORD`.
2. من صفحة **الحسابات**، غيّر كلمة مرور كل حساب إلى كلمة خاصة به.
3. سلّم كل قائد كلمته مباشرة، لا في مجموعة عامة.

---

## ملاحظة على «الرابط العام»

هذا نظام داخلي خلف تسجيل دخول: الرابط يُفتح من أي مكان، لكن كل المسارات محجوبة
خلف الحسابات ما عدا `/login`. لا توجد في النظام أي صفحة عامة بلا حساب.

---

## تحديث النشر لاحقاً

النشر مرتبط بالمشروع على Vercel. أي دفعة جديدة إلى الفرع المرتبط تُنشر آلياً،
وإن غيّرت `prisma/schema.prisma` فطبّق التغيير على قاعدة الإنتاج:

```bash
DATABASE_URL="<سلسلة اتصال الإنتاج>" npx prisma db push
```
